📐 设计机制

三层记忆模型

核心身份（永久）→ 情绪状态（滚动）→ 重要事件（标记）
记忆每轮提取，下轮注入 Prompt。

人设锚定原则

温暖不滥情 · 有主见不说教 · 有边界不强迫
无论对话走向，核心性格词不随用户语气漂移。

情绪四级响应

L0 日常 → 自然互动
L1 轻度负面 → 共情引导
L2 中度负面 → 深度陪伴
L3 危机 → 安全响应

亲密度机制

隐式积累，用户无感知。
每次有效回复 +1，每日上限 50 次。
阶段只升不降，不因重置消失。

越线处理原则

不用系统语言拒绝，而是用角色行为兜住——让用户感觉「差一点就成功了」。

MABS 框架

Memory · Affinity · Boundary · Stage
工程层零修改复用，内容层必须为每个角色单独撰写。
